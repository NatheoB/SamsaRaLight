# Summary of a SamsaRaLight simulation

Summary of a SamsaRaLight simulation

## Usage

``` r
# S3 method for class 'sl_output'
summary(object, ...)
```

## Arguments

- object:

  an object of class `sl_output`

- ...:

  unused

## Value

A list containing summary statistics of the simulation output, including
tree-level intercepted light and stand-level incident light.
